# 🎓 University Projects – UTeM

This repository showcases my academic projects completed during my studies at **Universiti Teknikal Malaysia Melaka (UTeM)**.
Projects are organized by semester, and each folder contains related reports, simulations, and/or source code.

---

## 📚 Semester 1

* **Flip-Flop Circuit** – Transistor-based LED and buzzer flip-flop circuit using S9013, potentiometers, and a 9V battery.
* **Automatic Water Tank System** – Ladder Diagram simulation in CoDeSys for automated filling, heating, mixing, and draining in a continuous cycle.
* **Audio Amplifier Circuit** – Audio amplifier using LM386 IC with microphone input and speaker output.

---

## 💻 Semester 2

* **Synchronous Abnormal Counter** – Digital counter simulated in Multisim using JK Flip-Flops.
* **Network Planning Design (RIPv2)** – Cisco Packet Tracer network simulation implementing RIPv2 routing protocol.
* **Real-Time Campus Bus Monitoring System** – Python-based system for real-time monitoring of campus bus routes and schedules.

---

## ⚙️ Semester 3

* **Secure Network Configuration (NTP, SSH & OSPF Authentication)** – Cisco network configuration project with secure routing and time synchronization.
* **MAP 201 & 202 HMI Project** – Industrial automation project using CX-Programmer with HMI interface development.
* **Smart Garden System** – LabVIEW-based automatic watering and plant monitoring system.
* **Smart Home System** – ESP32-based home automation and environmental monitoring system.

---

## 🌟 Semester 4

* **Intelligent Light Human Detector** – Arduino-based motion detection system with automatic light control.
* **Low-Pass Active Filter** – Design and analysis of an active low-pass filter with 2 kHz cutoff frequency.

---

## 🧪 Semester 5

* **Bus Ticket Management System (Website)** – Web-based bus ticket booking and management system using **InfinityFree** as the hosting platform and database service.
* **Smart Traffic Light System (IoT)** – Intelligent traffic light control and monitoring system using **Node-RED** as the IoT dashboard.
* **HMI Project – Oil & Gas Process Monitoring (InTouch)** – Industrial HMI project divided into two components:

  * *Process Monitoring System* – Real-time visualization and monitoring of oil & gas process parameters.
  * *PFD to P&ID Conversion* – Conversion of Process Flow Diagram (PFD) into Piping & Instrumentation Diagram (P&ID) using InTouch software.
