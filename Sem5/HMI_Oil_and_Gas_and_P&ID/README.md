# 🛢️ HMI Project – Oil & Gas & PFD to P&ID (InTouch)

This repository contains an industrial **Human Machine Interface (HMI)** project developed using **InTouch (Wonderware)** software.  
The project focuses on process monitoring in the **oil & gas industry** and engineering documentation through **PFD to P&ID conversion**.

## 📌 Project Overview

This HMI project was designed to:
- Visualize real-time industrial process data  
- Simulate monitoring systems used in oil & gas plants  
- Understand the relationship between **process flow diagrams (PFD)** and **instrumentation diagrams (P&ID)**  
- Gain hands-on experience in **industrial automation and HMI development**
