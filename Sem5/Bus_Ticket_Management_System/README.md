## ⚙️ System Description

The Bus Ticket Management System allows users to:
- View available bus routes and schedules  
- Book tickets online  
- Store and manage passenger information  
- Manage ticket records through a database  

The system is hosted using **InfinityFree** as the main web hosting platform, with a backend database to store booking and user data.

---

## 🧩 Basic System Flow
1. User accesses the website  
2. User selects route, date, and bus schedule  
3. User enters passenger details and books a ticket  
4. System stores booking data into the database  
5. Admin can view and manage booking records
